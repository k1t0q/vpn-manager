## DNS и HTTPS

Непосредственно на VPS и через публичный DNS подтверждена A-запись connect.caesarbot.ru → 185.23.239.142 с TTL 600. Изолированное окружение разработки не разрешало этот домен; вывод о DNS сделан по проверке с VPS и публичному ответу.

HTTPS рабочей панели на 8444 ответил HTTP 200 с проверкой сертификата. Запрос https://connect.caesarbot.ru/ завершился сетевой/TLS-ошибкой; конфигурация Caddy не содержит virtual host для connect.caesarbot.ru. Одной A-записи для публикации HTTPS-страницы недостаточно.

На текущем IP обычный HTTPS без номера порта приходит к Xray на 443. Новая веб-страница на том же адресе и стандартном порту требует отдельного внешнего HTTPS-прокси/входа, дополнительного IP или изменения маршрутизации 443. Последний вариант запрещён условиями задачи и не выполнялся.

Вариант без изменения Xray: отдельный HTTPS virtual host Caddy на уже используемом веб-порту, например connect.caesarbot.ru:8444, с отдельным действительным сертификатом. Это предложение, а не опубликованный адрес. Сертификат и маршрут для нового имени в данной задаче не устанавливались, поскольку основной механизм автоматического импорта не подтверждён. Текущий access logging в обоих Caddy HTTP-серверах выключен; будущий сервис выдачи профилей также должен исключать токены и конфиги из журналов.

## Что именно поддерживает DefaultVPN

Официальная документация подтверждает импорт .conf и текстового ключа vpn://:
https://docs.amnezia.org/documentation/alternative-clients/
Официальный сайт: https://dfvpn.com/.

Проверен публичный dev-код DefaultVPN на commit 3cee753b9fb3658ddebdc0982036979e08c7d8ba от 16 июля 2026. Соответствие этого публичного кода последней установленной App Store-сборке не подтверждено.

- client/ui/controllers/importController.cpp распознаёт [Interface]/[Peer], извлекает AWG-параметры из .conf и принимает текст vpn:// как Base64URL-пакет с qUncompress. Экспорт использует qCompress с 4-байтовой длиной и zlib. Это формат данных для импорта, а не доказательство регистрации URI в iOS.
- client/ios/app/Info.plist.in регистрирует документы .conf/.cfg/.vpn, но не содержит CFBundleURLTypes/CFBundleURLSchemes для vpn или defaultvpn.
- client/platforms/ios/QtAppDelegate.mm и AmneziaSceneDelegateHooks.mm обрабатывают file URL. Передача собственного URI в импорт в этих обработчиках не реализована.
- main.entitlements не содержит associated-domains для Universal Links. Проверенные CMake и workflow не добавляют регистрацию схемы.
- Поэтому превращение .conf в текст vpn:// само по себе не даёт работающую кнопку Safari → DefaultVPN. Это ограничение приложения, его нельзя устранить только кодом веб-панели.

## Технически осуществимая альтернатива

Персональная HTTPS-страница со скачиванием неизменённого .conf и инструкцией «Сохранить → Поделиться → DefaultVPN / импортировать из файла». Ручной импорт существующего .conf в DefaultVPN и подключение уже проверены владельцем. Возможен дополнительный вариант «Скопировать ключ» с последующей вставкой в DefaultVPN. Кнопку нельзя называть автоматическим подключением, если она лишь копирует текст или скачивает файл.

Предлагаемый вид, ещё не выданная ссылка:
https://connect.caesarbot.ru/<случайный-токен>
При размещении на текущем отдельном веб-порту:
https://connect.caesarbot.ru:8444/<случайный-токен>

Для реализации:
- 32 случайных байта токена (256 бит), Base64URL без padding; никакой последовательной нумерации в публичном URL.
- Существующий client_id связывается с одним действующим токеном. Продление не создаёт новый профиль и не меняет ссылку.
- В SQLite хэш токена для проверки и шифрованная копия для повторного копирования администратором; ключ шифрования отдельно на сервере. Уникальность, транзакции и повтор запроса без перевыпуска.
- Администратор может отозвать и перевыпустить ссылку. Отзыв блокирует дальнейшее скачивание, но сам по себе не отключает уже импортированный VPN-профиль.
- Отключённые/архивированные профили не выдаются. Доступ к конфигу только после проверки токена; нельзя принимать путь к файлу от клиента.
- Generic landing page без ключей в HTML, QR или предпросмотре ссылок. Конфиг выдаётся после явного действия.
- No-store, noindex/noarchive, Referrer-Policy: no-referrer, ограничивающая CSP, запрет внешней аналитики и ресурсов, rate limiting, одинаковые ответы для неизвестных и отозванных токенов. Access/error logs должны редактировать путь и не писать тело ответа.
- Сначала allowlist одного отдельного тестового клиента. До успешного iPhone-теста не создавать ссылки автоматически для всех пользователей.

Для точного сценария «Подключить VPN → приложение сразу предлагает импорт» нужна подтверждённая схема/Universal Link от разработчика текущей DefaultVPN-сборки либо изменение самого приложения. Смена серверных ключей, протокола или перевод существующих пользователей для этого не нужны.
